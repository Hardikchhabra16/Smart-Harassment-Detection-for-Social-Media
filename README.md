# Smart Harassment Detection for Social Media

## 📌 Overview
This project focuses on detecting harassment and abusive content on social media platforms using data analysis and machine learning techniques.

## 🧠 Problem Statement
Online harassment is increasing rapidly. This project aims to automatically identify harmful text content to help platforms moderate conversations effectively.

## 🛠 Technologies Used
- Python
- Jupyter Notebook
- Pandas, NumPy
- Natural Language Processing (NLP)
- Machine Learning (Basic Models)

## 📊 Features
- Text preprocessing (cleaning, tokenization)
- Harassment classification
- Exploratory Data Analysis (EDA)

## 📂 Dataset
The dataset contains social media text labeled as harassment or non-harassment.
It is used for training and evaluating the model.

## ▶️ How to Run
1. Clone the repository
2. Open `harassment_context.ipynb` in Jupyter Notebook
3. Run all cells

## ✅ Results
The model successfully classifies text into harassment and non-harassment categories using NLP and ML techniques.
